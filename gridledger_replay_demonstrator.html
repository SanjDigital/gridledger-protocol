How it works

This demonstrator uses the Web Crypto API (crypto.subtle.digest) to compute the SHA-256 hash of the canonical input string. The computation runs entirely within your browser; no data is sent to any server. This ensures that the verification process is private and trustless.

The pre-filled string represents the canonical record from Cycle 1 of the Nabiwi observational node. By matching the computed hash with the published seal, you verify the integrity of the data without relying on GridLedger's internal systems.
